# Start Match

> **Note:** 1:1 design with [Squat](../../Tactic/Tactic/Squat/squat.md). The same pitch diagram, local sub-navigation, and card rails. **Type 1** layout. Uses `GameplayScreen` shell.

## Differences from Squat

- The purpose is pre-match setup: confirm lineups, formation, set pieces, captain before kick-off.
- **[Sub On]** buttons are not present (substitutions happen during the match, not pre-match).
- The floating bottom navigation's 5th button changes from **Match** to **Kick-Off** while this screen is active. Tapping **Kick-Off** starts the match and navigates to [Match](../match/match.md).
