## Differences

- **2 slots**: Left Throw-in, Right Throw-in.
- Player dropdown sourced from squad, max 5 visible, scrolls beyond.
- Same player CAN take both sides.
- Empty slot: **+** + "Left Throw-in" / "Right Throw-in".
