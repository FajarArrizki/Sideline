# Serch Staf

> **Note:** Same design as [Serch Player](../Serch%20Player/serch%20player.md). **Type 1 — Sub-Navigation Rail.** Transfer sub-nav remains above. Uses `GameplayScreen` shell from [global.md](../../../global.md). Only the Position filter and Position column values differ.


## Differences from Serch Player

### Filter Overlay

Position field uses staff roles instead of player positions:
- Assistant Manager, Goalkeeping Coach, Attacking Coach, Defensive Coach, Technical Coach, Fitness Coach, Set Piece Coach, Scout, Head of Youth, Physio
- No Contract section (expiring/free agent filters removed).

### Table

Same columns: ★ (wishlist), Name (face+name), Position, Age, Rating.
- **Position** displays staff role (e.g., "Assistant Manager", "Goalkeeping Coach").
